# 🌌 Space Debris Risk Reporter

A modern, interactive **dashboard** that tracks and visualizes potential conjunctions (close approaches) between the **International Space Station (ISS)** and **space debris**.  
Built with **Streamlit, Skyfield, and Plotly**, the app provides real-time alerts with a dreamy animated UI ✨

---

## ✨ Features
- 📡 **Real-time ISS Conjunction Tracking** using live TLE (Two-Line Element) data from CelesTrak  
- 📊 **Interactive Risk Dashboard** powered by Plotly  
- 🚨 **Conjunction Alerts Summary** with risk classification  
- 🌙 **Dark & Light Theme Toggle** (Aurora gradient or Starry night mode)  
- ⭐ **Floating Star Animation** for immersive visuals  
- 🧾 **Mission Report Placeholder** (future: AI-generated summaries using Hugging Face LLMs)
